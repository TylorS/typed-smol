# Scope

In scope:

- Runtime route continuation registry and DataAttr resume payload decode.
- Compiler-generated continuation registration metadata.
- Resume trigger boot behavior for `data-typed-resume`.
- Serializable event action metadata and boot-time listener restoration.
- TypeScript capture/syntax coverage hardening.
- First-party UI resumability for Disclosure, Checkbox, Popover, Dialog, and Select.
- Shared diagnostic parity and generated coverage matrix.

Out of scope:

- A second HTML metadata channel.
- Reintroducing Hydratable.
- Preserving arbitrary heap state.
- Reverting unrelated dirty worktree changes from other agents.
